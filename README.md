# 💰 Pencatat Keuangan Harian

Aplikasi pencatat pemasukan dan pengeluaran harian berbasis Android.

## ✨ Fitur Utama
- Catat pemasukan & pengeluaran dengan cepat
- Rekap saldo dan riwayat harian otomatis
- Ekspor & impor data (JSON / CSV)

## 📥 Cara Unduh APK
1. Buka tab **Actions** di repositori ini.
2. Pilih workflow **Build Android APK** terbaru.
3. Unduh file di bagian **Artifacts**.
